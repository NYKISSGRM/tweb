NYKISS Gram

Gram как приложение

Ставится за полминуты, без магазина. Отдельное окно, свой значок, запуск в один клик. Обновляется само.

Android

Chrome или Samsung Internet

  1. Откройте Gram в Chrome.
  2. Нажмите меню ⋮ справа вверху.
  3. Выберите Установить приложение (или «Добавить на главный экран»).
  4. Подтвердите. Значок NYKISS появится среди приложений.

Или установите готовый файл: скачать APK. Android один раз спросит разрешение на установку из этого источника: разрешите. Если Google Play Protect предупредит, нажмите «Всё равно установить».

Windows и Mac

Chrome или Edge

  1. Откройте Gram в Chrome или Edge.
  2. В адресной строке справа нажмите значок установки (монитор со стрелкой).
  3. Нажмите Установить.
  4. Gram откроется в своём окне. Закрепите его на панели задач или в Dock.

Значка нет? Меню ⋮ → «Трансляция, сохранение и общий доступ» → «Установить страницу как приложение».

Или отдельное приложение: скачать для Windows и Mac (установщик Setup.exe или portable-версия для Windows, .dmg для Mac). Приложение не подписано: Windows покажет «Подробнее → Выполнить в любом случае», Mac: правый клик по приложению → «Открыть».

iPhone и iPad

Только Safari

  1. Откройте Gram в Safari.
  2. Нажмите кнопку Поделиться (квадрат со стрелкой вверх).
  3. Выберите На экран «Домой».
  4. Нажмите Добавить.
Открыть Gram

Установка не заменяет вход: аккаунт и ключ остаются такими же. Если приложение не ставится, обновите страницу Gram и попробуйте ещё раз.
